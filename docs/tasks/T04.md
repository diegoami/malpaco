  `tests/core/save.test.ts` (all new). No UI change. No board change (T03 is done). The deal, the
  turn, reinforcement, combat-update, victory and leaving a game are T05+.
- **Scope**: the foundation every later core-rules chunk sits on. Define **GameOptions** with the
  11 fields and defaults from `design/core-rules.md` § Setup → Options (seats, board, starting armies
  range, human share, computer strength, event frequency, domination win, round limit, game seed,
  speed, sound), every option with its range. Add **SeatKind** (`"human" | "computer"`) to the
  player record and 2–4 seats to a game's options (decision 3). Replace the single RNG stream with
  a **game stream + one stream per computer seat**, the latter seeded from the game seed and the
  seat number so computer choices never shift the game's draws (C-RND-03). Add a **save format
  version** constant and a `serialize`/`deserialize` pair that round-trips an options object and
  rejects wrong-version, missing-field or out-of-range files with a typed error (C-SET-05, C-SET-07).
  Extend `newGame` to accept `GameOptions`; keep the current `newGame(map, rules, players, seed)`
  as a thin overload the spike's tests still call. Every constant cites its C-* claim (rule 17).
- **Done when**:
  1. `npx vitest run tests/core/options.test.ts tests/core/seats.test.ts tests/core/rng-streams.test.ts tests/core/save.test.ts` passes; each of the four files fails on `main` today.

  3. `seats.test.ts`: a `SeatSpec` accepts 2 to 4 seats (decision 3); a game with zero human seats is valid (watching); 5 seats is refused with a typed error.
  4. `rng-streams.test.ts`: `DeterministicRng.subStream(parentSeed, childSalt)` returns a stream whose first 1000 draws equal a hand-computed reference for a fixed seed and salt (no regressions in the parent's sequence); a computer seat's stream never perturbs the game stream's sequence when used independently (C-RND-03); 6000 rolls on each of 6 sides land every face between 900 and 1100.
  5. `save.test.ts`: `serialize` then `deserialize` of a default `GameOptions` round-trips; a payload with the wrong version, a missing field or `seats: 5` is rejected with a `SaveFormatError` and the message names the field; valid file format is plain readable JSON, not base64 or ciphered (rule 18 in `core/`, C-SET-07).
