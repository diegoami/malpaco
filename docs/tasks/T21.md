- **Owns**: tools/release/**, tests/release/**, playwright.release.config.ts,

  docs/play.md, docs/prototypes/playable/**.
- **Scope**: Provide `npm run package:playable` to build and package a clean
  `release/malpaco-playable/` plus downloadable tar.gz. Include static assets,
  original concise PLAY instructions, a dependency-free Node 22 loopback static
  launcher, source-commit metadata and SHA-256 inventory. A recipient extracts,
  runs the documented command and opens setup without the source checkout,
  npm install, Vite or network assets. Explain human/computer play, help,
  save/load, New game, supported desktop sizes and current limitations.
  CI tests the extracted artifact and uploads the playable archive. No new
  dependencies, public deployment, game rules/features or existing assertion edits.
- **Done when**:
  1. `node docs/prototypes/playable/acceptance.mjs <fresh-directory>` packages,
     extracts outside the checkout, verifies archive contents/metadata/inventory,
     serves with the bundled launcher and checks root plus every referenced asset.
     Exclude source, node_modules and repository metadata; recipient needs Node 22.
  2. `npx playwright test --config playwright.release.config.ts --workers=2`
     uses only that extracted static artifact and reuses existing browser suites
     unchanged: setup, human/computer turns, complete conquest/restart, help and
     save/load all pass at 1280x800 and 1920x1080. Retain captures and no-error proof.
  3. Acceptance fails with packaging absent, passes with a disposable actual-source
     candidate, and removing the extracted entry asset fails the asset check.
     Restore exact bytes; retain logs, exits and hashes without overwriting runs.
  4. `npm test`, `npm run build` and normal full pinned browser suite pass;
     CI uploads the tested archive. No golden or existing assertion changes.
- **Hazards**: Never test the Vite server by mistake; use a separate port and
  extracted path. Rebuild instead of shipping stale dist. Launcher resolves assets
  relative to itself, binds loopback and serves correct MIME types. Stop child
  servers reliably; package no secrets. Only remove generated release outputs.
