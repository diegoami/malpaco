- **Kind**: infrastructure
- **Issue**: #1 · **Branch**: `task/T01-skeleton` · **Merge after**: —

- **Reviewer**: opencode `luna` (GPT-6 Luna, high), another family
- **Why**: The owner decided on 2026-10-03 to restart malpaco in TypeScript, from the spike built
  and reviewed in malpaco-godot-poc. Review 006-02 found no blocking finding in it. The spike
  becomes the project's walking skeleton (`docs/process.md` §0). Every later task builds on it.
- **Evidence**:
  - malpaco-godot-poc, commit `8c3de7d91357ac3c5cd285b5a6064b2b5318428b` (the merge of PR #9):
    `spike-ts/`, `data/maps/small_sea.json` (malpaco's own map, not an original game file), and
    reviews `006-ts-spike-impl-01.md` and `-02.md`.
  - Spike CI at its last head: Vitest 32/32 and Playwright 22/22 (run 37105822801).
- **Owns**: everything except the harness copy, `harness.lock`, `CLAUDE.md`, `README.md` and
  `docs/tasks/**`.
- **Scope**:
  - **Import `spike-ts/` to the repository root, unchanged except for paths:**
    - `package.json`, `package-lock.json`, the configs, `index.html`;
    - `src/core/` with its `tsconfig.json`, and `src/ui/`;
    - `tests/` (Vitest and Playwright);
    - `data/maps/small_sea.json`;
    - `spike-ts/SPIKE.md` moved to `docs/spike.md`.

    Every `SPIKE STAND-IN` tag stays.
  - **Path fixes only**: the map's import path, config globs, and the workflow's working directory.
    No behaviour, rule, style or test changes.
  - **CI**: `.github/workflows/ci.yml` runs `npm ci`, `npm run build` (the core config first),
    `npx vitest run` and `npx playwright test`, and uploads the screenshots as an artifact.
  - **Not in scope**: review 006-02's seven findings (T02), and any new rule or UI work.
- **Done when**:
  1. `npm ci && npm run build && npx vitest run && npx playwright test` passes locally and in CI,
     with Vitest 32/32 and Playwright 22/22.
  2. Each mutation fails and is restored, shown in the PR:
     - the seed ignored in the `DeterministicRng` constructor (the determinism tests);
     - `Math.random()` in `src/core` (the purity guard);
     - `#map .provinces { opacity: 0; }` (the "board is painted" test).
  3. Every imported file is byte-identical to its source at `8c3de7d`, except the files the PR lists
     as path-only edits; each of those shows its diff. A short script in the PR body proves it, and
     its output is pasted there.
  4. Nothing depends on Godot. Every mention of it is a provenance comment kept byte-identical from
     the spike: `grep -rniE 'godot|gdscript|\.gd\b' src tests | grep -vE ':[0-9]+:\s*(\*|//|/\*)'`
     prints nothing.
  5. CI uploads the screenshot artifact, five PNGs per size, and the run is green.
- **Hazards**:
  - Cloning malpaco-godot-poc inside the worktree, which nests a repository, or writing outside the
    worktree, which L26 fails. Instead run
    `git fetch git@github.com:diegoami/malpaco-godot-poc.git 8c3de7d91357ac3c5cd285b5a6064b2b5318428b`
    and then `git checkout FETCH_HEAD -- spike-ts data/maps/small_sea.json`, then `git mv`.
  - "Improving" the spike while moving it: T02 owns the known fixes.
  - Committing `node_modules`, `test-results` or the screenshots (`.gitignore` covers them).
