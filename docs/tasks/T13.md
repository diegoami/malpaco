- **Evidence**: T05a/T05b's generated topology (46 countries, 9 islands, 16 sea
  lanes), T12's UI gates, and `docs/prototypes/generated-board/` preflight.
  Using the existing label-box estimate, seeds 1, 2, 3, 7, 42 and 1994 have

- **Owns**: `src/ui/prototype/**` (new), optional presentation helpers under
  `src/ui/`, prototype-scoped CSS in `src/styles.css`, opt-in routing in
  `src/main.ts`, `tests/ui/generated-board-layout.test.ts` (new),
  `tests/e2e/generated-board.spec.ts` and its new goldens,
  `docs/prototypes/generated-board/**`, and affected descriptions in `docs/spike.md`.
- **Scope**: Build the owner-selected geographic island map as a separate preview at
  `?view=generated-prototype&seed=1994`. Display all countries and island bonuses;
  distinguish land adjacency from sea lanes with explicit connection indicators
  where geography alone could mislead. Clicking or keyboard-selecting a
  country names it and exposes/highlights its exact neighbours. Include a seed
  control and visible generation failure with retry. Preserve generated IDs,
  names, membership, bonuses, edge sets and input objects; projection consumes
  no rule RNG. Export `layoutGeneratedBoard(map): GameMap` from
  `src/ui/prototype/layout.ts`; only presentation geometry/bounds may change.
  The ordinary playable route keeps its current board and goldens.
  Game setup, placement/combat integration and a permanent visual-design choice
  belong to later work. The owner judges the prototype's look from screenshots.
- **Done when**:
  1. `npx vitest run tests/ui/generated-board-layout.test.ts` passes: seeds
     1/2/3/7/42/1994 produce stable, complete layouts without mutating maps or
     changing semantic fields; all 46 label/hit regions are distinct and in bounds.
  2. `npx playwright test tests/e2e/generated-board.spec.ts` passes in the pinned
     image at both viewports: 46 painted/selectable countries, 9 islands, full
     names at least 11 rendered pixels, no overlapping labels or page overflow;
     click/keyboard selection reports exact border/sea neighbours, 16 sea links,
     seed change/reload and generation failure/retry work. New goldens pin the
     preview; provide settled screenshots for visual judgement.
  3. The same suite fails when a country is unpainted or a neighbour link is
     removed; report deleted lines/tests and restore exact source, then green.
  4. `npm test`, `npm run build` and full pinned-image `npx playwright test` pass;
     original playable-screen goldens and `src/core/**` remain unchanged.
- **Hazards**: Do not invent neighbours from geometric proximity or force shared
  polygon edges that disagree with the graph. Stop on infeasible visual constraints;
  never alter generation/fairness to make the preview fit.
