- **Scope**: export pure `createGame(options: GameOptions, rules?: RuleSet): { ok: true; state: GameState } | { ok: false; errors: string[] }`, defaulting to `classicRules()`. Validate options with the existing typed validator. Generate the board, including retries, from one game RNG; continue that same stream through the following six steps. Board exhaustion returns the generator's failure, never a partial game. Keep `generateBoard(seed)` output compatible; extend its implementation with a shared-stream seam. Keep the existing map-based `newGame` overloads and spike UI behaviour; their compatibility is documented. Generated games start in the current `attack` phase; turn/income/placement wiring is a later task.

  1. Draw the first seat uniformly; turn order wraps from that seat.
  2. Give each seat `floor(46 / N)` countries; give the remainder to the last seats in turn order. Apply `humanShare` per human, in turn order: positive transfers from the largest computer share (later on ties); negative transfers to the smallest computer share (earlier on ties). Never transfer between humans; never reduce a computer below 3; ignore the setting without computers or without humans.
  3. Fisher–Yates shuffle countries and fill each share in turn order.
  4. Repair complete islands by swapping with another owner, choosing randomly among eligible pairs that complete no island for either owner. Preserve every share. If no eligible repair exists, return an explicit failure; never hang or weaken the rule.
  5. Give each country 1 army, then randomly distribute the remainder under the selected top (2, 3, or 4). Each seat's exact total is `floor((1 + top) * countryCount / 2)`, so rounding follows multiplication, including odd counts.
  6. Draw exactly 3 distinct production-centre countries uniformly, with no owner, island or spacing condition.

  Store `productionCentres: string[]` on `GameState`; legacy games use an empty list. Clone it independently. Computer streams remain seeded solely from the game seed and seat index. Centre effects, cards, UI wiring, turn phases, combat changes and board algorithm/fairness changes are outside scope.
