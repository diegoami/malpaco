# T136 Bounded attack-campaign outcomes

- **Kind**: public probability-model slice of #341/#334 and #353; issue #356; branch `task/T136-campaign-model`; experimental only.
- **Evidence**: T130 single-die interval model, T133 strict-advantage/remaining-budget gate, T134 preserved cutoff where a large nominal gap gives negligible capture chance within96 exchanges. Movement T135 supplies a stopping alternative; attack ranking follows separately.
- **Owns**: new `src/core/computer-campaign.ts`, core exports, exact-oracle/model tests, helper documentation. No policy routing/rule/save changes.
- **Scope**: Given one legal public attack pair, model repeated single-die exchanges until capture, strict army advantage/minimum fails, or the existing remaining attack budget is exhausted. Each resolved exchange removes one army, so wins+losses is the consumed budget. Return outward fixed-point bounds on each terminal outcome (defenders lost,own losses,capture), capture probability and expected losses for both sides. Rerolled ties consume one resolved exchange; attacker/defender ties use the appropriate probability. Zero remaining budget/no initial advantage has an exact unchanged terminal state. [Designed] scale1000000,max16384 grid cells checked before allocation; canonical terminal order. No hypothetical reinforcements, capture allocation, counterattack/card prediction or extra engine action. Unsupported rules (including failure penalties)/illegal pair/unsafe arithmetic/budget return explicit unknown, never zero likelihood. Partial defeat outcomes remain available for later objective scoring; armies conditioned on a capture are not a point estimate of future safety.
