- **Scope**: define the 5 fairness checks as **pure** functions, wire them into
  the generator with a bounded retry loop, and fix a small, named number of
  attempts. Each check takes a `GameMap` and returns the list of violations
  (an empty list means the check passes):

  1. **Bonus out of proportion**: any island whose `bonus > size` (a small
     rich island, however the bonus got there). Cites C-BRD-01.
  2. **Fortress**: any island of size ≥ 7 with exactly one country carrying a
     sea lane (a "single-entrance" island that size can be held by one
     country), **or** more than 3 islands (any size) with a single entrance.
     "Single-entrance" = an island where exactly one of its countries has a
     non-empty `seaLanes` list. Cites C-BRD-01.
  3. **Easy bonuses concentrated**: the sum of `bonus` over the single-
     entrance islands is more than a quarter of the sum of all `bonus`.
     Cites C-BRD-01.
  4. **Remote / hub island**: in the island graph (vertices = islands, edges
     = pairs where at least one country of one has a sea lane to a country
     of the other), any island with eccentricity > 4 (more than 4 crossings
     from some other island) or degree > 4 (touching more than 4 others).
     Cites C-BRD-01.
  5. **Crowded crossing country**: any country with more than 2 sea lanes.
     Cites C-BRD-01.

  The retry loop calls the existing T05a generator body, runs the 5 checks
  on the result, and rejects when any check returns a non-empty list. **The
  cap is a named, exported constant** `MAX_BOARD_ATTEMPTS` (e.g. 50; the
  implementer picks the smallest number that, on a 200-seed sweep, gives a
  near-100% success rate — the value is fixed by a test, not by an
  implementation detail). The retry consumes the `DeterministicRng` between
  attempts, so each attempt draws a different plan; the generator never
  re-uses the same plan twice in a row.

  When the cap is reached, `generateBoard(seed)` returns
  `{ ok: false, errors: ["fairness checks failed after N attempts: …"] }` —
  the `ok: false` branch is already part of the public type. **Falling back
  to T03's `archipelago.json` is not in scope** (T03 is a single board, not a
  per-seed fallback; the design's parenthetical "for example" is one option,
  not a mandate, and a per-seed curated set is a different feature). If the
  design team later wants a per-seed fallback, that is its own task.

  The 5 `test.skip` placeholders in `tests/core/board-gen.test.ts` (T05a's
  mechanical migration) are replaced with real tests that run the 5 check
  functions on the generator's output and assert no violations. A
  `tests/core/board-fairness.test.ts` adds synthetic-map tests for each
  check: a hand-built `GameMap` that violates only that one check, asserting
  the check catches it and the other four pass on a hand-built valid board.

- **Hazards**:
  - **Weakening a check to make generation easier.** The design says don't;
    one of the 5 may need redesign once it is enforced and a counterexample
    arrives (the implementer stops and reports; the contract says so).
  - **The retry loop hiding a structural problem.** If the success rate is
    < 99% on a 200-seed sweep, the underlying generator needs redesign, not a
    bigger `MAX_BOARD_ATTEMPTS`. Cap at 200; report above that.
  - **A hand-built map that happens to also violate another check** in the
    synthetic-map tests. Each test's "violates only this check" map must
    pass the other 4; build them carefully, assert both directions.
  - **Confusing "single entrance"** (one country with sea lanes) with
    "exactly one sea lane" (which would be a country-level count, not an
    island-level property). The design means the former.
  - **A retry loop that draws the same plan twice.** Consume the
    `DeterministicRng` between attempts, not just the state — a new plan is
    only new if the rng advanced past the prior draw sequence.
  - **Returning `{ ok: false }` for a structurally invalid board** that should
    not have been generated in the first place. The T05a generator already
    guarantees structural validity; `ok: false` is reserved for fairness
    exhaustion.
  - **Falling back to T03's `archipelago.json`** (a single board, not a per-
    seed fallback). The task explicitly rules this out; report the design
    change as a follow-up if the cap is too tight.
  - **Coupling the deal.** T05b still returns a `GameMap`, not a `GameState`;
    T06 wires the generator to the game stream.
  - **Reading the time** ("X attempts took Y ms; if too slow, fail"). The
    cap is a count, not a duration; rule 18 forbids wall-clock.
