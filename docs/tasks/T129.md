# T129 Public strategic context and objective-free position facts

- **Kind**: slice of #341, following #339; issue #343; branch `task/T129-public-position`.
- **Review**: optional PR review; recommended before later strategic-policy adoption. No automatic reviewer.
- **Evidence**: [decision-space research](https://github.com/diegoami/malpaco/issues/339#issuecomment-6394494968), owner-directed #334/#341; existing income, island, movement and victory rules. Coordinates #92 without claiming its broader contract complete.
- **Owns**: `src/core/computer-view.ts`, new `src/core/computer-position.ts`, core exports, `tests/core/computer-position.test.ts`, `tests/core/computer-strategy-view.test.ts`, existing projection whitelist assertion and evaluator documentation.
- **Scope**: Extend the existing view with a copied strategic context containing public island membership/bonuses, combat rules, recurring-income/turn-sequence context, current/round seat order, victory threshold/limit, capture bounds and captured-this-turn flag. Retain the existing narrow decision interface for historical synthetic inputs. Add a pure integer evaluator returning per-seat country/army/income totals and island progress, per-country frontier/owned-route distance and movable armies, and adjacent enemy sources grouped by opponent. Count each enemy source once in a seat's aggregate adjacent pressure, even when it touches multiple countries. Canonicalize evaluator output under country/island/neighbor permutations. Pressure describes current public adjacency, not capture odds, independent threats, future income or a battle plan. Add no weights, lookahead, policy choices, rules, RNG draws, save identities or UI.
- **Done when**:
  1. `npx vitest run tests/core/computer-strategy-view.test.ts`: independent context expectations, deep-copy mutations, separately varied/poisoned enemy hands, draw order, RNG streams and other controllers prove public-only projection and unchanged decisions.
  2. `npx vitest run tests/core/computer-position.test.ts`: hand-calculated multi-island income/progress, divisor/turn-sequence variants, exposure, disconnected reserve routes, land/sea adjacency, distinct opponents, deduplicated sources and permutation cases pass; compare income with the engine oracle on ordinary generated states. New assertions fail against pre-change source.
  3. `npm run build`, `npx tsc --noEmit -p .`, `npm test`, pinned affected computer-card/reserve/persistence browser suites and exact-head CI pass. Existing T128/action-replay coverage and baseline choices remain intact; retain commands/results in ignored artifacts and link evidence on #343/PR.
- **Hazards**: Return no mutable engine references or hidden/control fields. Public pressure must not pretend the same army independently attacks every neighbor. No arithmetic or strategic-strength claim exceeds the tested facts.
