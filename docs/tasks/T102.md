# T102 Balanced starts

- **Kind**: rules (0.3; moved from 0.2.1 by the owner, 2026-10-22)
- **Issue**: #256 · **Branch**: the session branch · **Merge after**: 0.2.1 (T99)
- **Review**: none per PR; the 0.3 milestone review covers it.
- **Evidence**: the owner, 2026-10-22, after a play test in which one computer's island bonuses snowballed (income 9, 15, 16, 25, 26) to a round-6 Domination: "try to make balanced starts". The current deal follows C-STA-01..07 (`src/core/setup.ts`); the balanced deal is a **[designed]** departure the owner asked for, marked so in the code.
- **Owns**: `src/core/setup.ts`, `src/core/options.ts`, `src/core/match-save.ts` (a new identity version only), `src/ui/geographicGame.ts` (new games take the new identity), `tests/core/balanced-deal.test.ts`, the 0.3 acceptance record (a line), `docs/play.md`, `tools/release/PLAY.md`, and the existing tests the change makes wrong.
- **Scope**:
  - **New games deal balanced starts**; saved games keep the deal they were made with.
    - Countries: every seat gets an equal share (they differ by at most one), as now.
    - Spread: no seat starts with more than `ceil(n / seats)` countries of any island of `n` countries, so nobody starts near an island bonus.
    - Armies: every seat's starting armies total the same (within one army), as the share formula gives.
    - Position: each seat starts on at least two islands, and no seat's countries are all on one side of the map's island graph; use a simple measure, such as each seat's countries touching at least as many enemy borders as the seat with the fewest plus a small margin. Choose it, document it, and test it.
  - The deal stays deterministic from the seed (a seeded constructive deal, or seeded redraws with a fixed attempt cap and a fallback that satisfies the spread rule).
  - The deal is versioned: the rules or generator identity gains a new version for new games, and replays of every older identity are byte-for-byte unchanged.
  - The Nine Isles reference board and `?setup` games may stay on the old deal; say which in the PR.
- **Done when**:
  1. `tests/core/balanced-deal.test.ts`: over 500 seeds the spread, share, armies and position rules hold for 4 seats (and for 2 and 3 seats on `?setup`, if they use the new deal), and the deal is identical for the same seed.
  2. A simulation over 200 seeds of four Normal computers (core only, no UI): the first seat's win rate and the spread of round-5 incomes are reported in the PR, before and after. No numeric threshold; the owner judges.
  3. Every existing save fixture replays unchanged (the existing replay and save tests pass untouched).
  4. `npm test && npm run build` and the source browser suite pass.
- **Hazards**:
  - **Replays.** A save carries its identity; the old deal must stay reachable for old identities forever.
  - **Rule 13.** Every new constant is marked `[designed]` with what was searched.
  - **Purity.** `src/core` stays pure: seeded RNG only, integer arithmetic.
