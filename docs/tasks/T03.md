- **Claude fallback**: sonnet
- **Reviewer**: opencode `luna` (GPT-5.6 Luna, direct OpenAI, high) · **Claude fallback**: opus
- **Evidence**: the promoted spec's `board.md` (C-BRD-01..04) and `island-bonuses.md` (C-BON-02):
  behaviour and design only. The originals' names, positions and exact 80-link topology never enter
  (rule 19); the owner chose structural fidelity (2026-10-07).
- **Owns**: `data/maps/archipelago.json`, `tests/core/archipelago.test.ts`, and — only if the
  implementer wants construction help — a deterministic, seeded or seedless-deterministic script
  under `tools/board/`.
- **Scope**: author the game's one board as a data file the existing reader validates unchanged:
  46 provinces, 9 islands of sizes 3, 5, 5, 10, 3, 7, 3, 7, 3 in that order, each island a
  consecutive range of the province order (C-BRD-03); our own adjacency with every province at 2 to
  5 neighbours (exactly 8 with 2, 12 with 3, 22 with 4, 4 with 5), exactly 16 inter-island links as
  sea lanes, one connected graph (C-BRD-04); island bonuses 2, 4, 4, 8, 2, 5, 2, 5, 3 in island
  order (C-BON-02). Placeholder polygons (at least 3 points, `[designed]`), label points within
  bounds; names and layout ours. The UI keeps `small_sea.json` — no `src/` change, no golden
  change. The deal, seats and first seat are T04's.
- **Done when**:
  1. `npx vitest run tests/core/archipelago.test.ts` passes; it fails on `main` today.
  2. The suite reads only the JSON file and asserts: `parseMap` accepts it; 46 provinces in 9
     islands whose lists partition the province order into consecutive ranges of sizes
     3, 5, 5, 10, 3, 7, 3, 7, 3; bonuses 2, 4, 4, 8, 2, 5, 2, 5, 3 in island order.
  3. The suite asserts the graph: degree counts {2: 8, 3: 12, 4: 22, 5: 4}; exactly 16 undirected
     sea-lane links (32 directed entries, symmetric, on `parseMap`'s own checks); the border-plus-
     sea-lane graph is connected.
  4. Rule 9, shown in the PR: changing any one structural constant — one bonus value, one island
     size, adding or removing one sea lane, moving one border off its island — fails the suite;
     applied, run, restored.
  5. `npm ci && npm run build && npx vitest run && npx playwright test` is green; `git status
     --porcelain tests/e2e` is empty (the UI did not move).
  6. `grep -c 'C-BRD-0[34]\|C-BON-02' tests/core/archipelago.test.ts` prints at least 3: each
     constant sits beside the claim it traces to (rule 17).
- **Hazards**: copying the original's exact topology or any original name (rule 19 — structural
  fidelity only); fudging a degree or the crossing count to ease authoring (these constants trace
  to findings; `[designed]` is not available for them); an unseeded script silently left as the
  map's source of truth (the JSON is the deliverable); touching `src/` or the goldens (not owned).
