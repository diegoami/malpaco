# T160 Automatic region choice for ambiguous taps

- **Kind**: owner-requested interaction correction #419; parent #422.
- **Branch**: `task/T160-automatic-taps` · **Merge after**: T159.
- **Review**: none; owner launches milestone review, geometry/gesture regressions required.
- **Owns**: map-camera touch resolution, host region callback, related unit/browser tests and Help/manual/provenance.
- **Scope**: replace the ambiguous-touch chooser with automatic choice by greatest visible region area under a circular contact footprint. Radius is max(width,height)/2 clamped to 12–24 CSS px. Measure actual country cell fills through their screen transforms with a deterministic 2px sampling grid; labels/badges never enlarge region area and non-map overlays contribute no area. Equal samples prefer the centre region, then stable region id. When multiple regions overlap the footprint, choose the winner once and zoom 1.25× about the tap, capped at existing MAX_ZOOM. Route the id through ordinary action validation, suppress the ensuing browser click so it cannot act twice, and preserve all armed/unarmed action semantics. Pan/pinch/cancel never resolve a choice. Keep manual country-list access in diagnostic adapters; remove only the touch chooser behavior. Preserve mouse and keyboard selection.
- **Done when**:
  1. Unit checks cover dominant surface versus centre hit, narrow patches, ties, water and bounded contact radius. Browser tests use an independent denser geometric measurement on real borders and show the expected single legal action, 1.25× zoom and no popup; the new behavior fails before implementation.
  2. Browser checks cover rotated/zoomed maps, a larger contact, synthetic follow-up click suppression, cancelled gestures and pan/pinch. Match history/RNG agree with ordinary engine actions; invalid or paused selections remain blocked. Existing country-picker/map-camera/guided-tap and keyboard checks remain valid.
  3. Build/root types, units and affected browser/manual checks pass; guide/Help and capture provenance updated. Any identical illustrations retain their inspected bytes. CI green before merge. No core rule, AI policy, save identity or published-asset changes.
- **Hazards**: centre or badge hit testing is not surface area; do not pick by bounding-box size, select twice, zoom after a drag/cancel, count covered UI as visible map, or mutate game state outside the normal handler.
