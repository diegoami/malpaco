- **Evidence**: core combat/rules, T11 reinforcement, T15/T18 setup/computer
  flow, T17 replay saves and existing keyboard map handlers. Help copy/layout
  are [designed] after inspecting these implementations; describe only shipped
  behavior, not unimplemented GameOptions promises.
- **Owns**: src/ui/**, src/styles.css, tests/e2e/help.spec.ts, tests/ui/**,
  docs/prototypes/help/**, README.md, affected docs/spike.md.
- **Scope**: Add accessible How to play help from setup and generated gameplay,
  using a readable modal with keyboard opening, Close/Escape and returned focus.
  Cover seed/player choices; numeric seat/army labels and explicit land/sea links;
  spend reinforcement pool on owned provinces then Start combat; select source
  and adjacent enemy, minimum two armies and at least defender strength, one
  exchange per Attack, Continue and optional End turn; elimination/full conquest;
  computer turns; Save download/Load replay and New game. No invented difficulty,
  hazards, domination or other unimplemented rules. Keep text concise and original.
  Opening/closing help preserves match, selection and settings. Pause computer
  timers while help is open, resume on close, cancel safely on disposal. Leave
  authored/prototype routes unchanged; no dependencies or rule changes.
- **Done when**:
  1. `npx playwright test tests/e2e/help.spec.ts --workers=2` passes both pinned
     viewports: help reachable through actual setup/generated controls, all named
     topics readable, keyboard Close/Escape returns focus; scrolling reaches all
     copy without clipped controls or horizontal overflow. Retain screenshots.
  2. Same suite compares actual downloaded match/options/history before and after
     help, preserves current selection/setup choices, then continues ordinary play.
     Open during a computer turn, advance virtual time and prove no action fires;
     close and prove automation resumes; replacement/New game leaves no stale timer
     or dialog. No browser errors, normal battle dialog behavior unchanged.
  3. New help acceptance fails without help and passes with disposable candidate;
     actual-source removal of content and computer pause each fail acceptance.
     Restore exact bytes; retain command exits, hashes and screenshots.
  4. `npm test`, `npm run build`, full pinned `npx playwright test --workers=2`
     pass. Only affected setup/generated goldens may change for Help controls,
     with reasons; authored/prototype goldens and prior assertions stay intact.
- **Hazards**: Scope dialog styles; prevent Escape bubbling into selection clear.
  Clear/resume only the current controller; preserve deterministic action replay.
