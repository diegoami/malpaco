# T94 Regional flavour names

- **Kind**: slice (0.2.0; owner, 2026-10-21: "names must be flavored in release 2").
- **Issue**: #170 · **Branch**: the session branch · **Merge after**: T93.
- **Review**: none; self-review in the session (#222 Q1). The owner judges whether the names add flavour.
- **Evidence**: #170 and the owner's answers there (2026-10-21): all five themes; the default is chosen per seed; generated maps only; chosen at new-game setup only. Name data are real place names, curated with a source per island; the pool sizes and the size-ranking rule are [designed].
- **Owns**: src/core/flavour-names.ts (new: data and the naming derivation); src/core/geographic-board.ts and src/core/options.ts (apply and record the theme); the setup view's region control; tests/core/flavour-names.test.ts; tests/e2e/flavour-names.spec.ts; the pinned map hashes in the geographic specs.
- **Scope**: Five themes: Mediterranean, Caribbean, Scandinavian islands, Malaysia/Indonesia and Pacific. Each supplies real island names with real town names that belong to each island. A generated map gives its larger islands the larger real islands, and each island's countries take that island's towns. With no choice made, the seed picks the theme. The setup view offers the theme (or "By seed"); it is fixed for the game and saved in its options. Naming uses its own derivation from the seed, never the game RNG, so changing only the theme changes no geometry, ownership, army, dice or outcome. Saves without a theme keep their stored names. The authored Nine Isles map keeps its names.
- **Done when**:
  1. `npx vitest run tests/core/flavour-names.test.ts` — Every theme names every island and country of every generated map in the fairness corpus with no duplicates; towns come from their own island; the larger island gets the larger real island; the same seed and theme give the same names; changing only the theme leaves the generated map, apart from names, and a scripted game's actions, dice and outcome identical; a save without a theme loads with its stored names.
  2. `npx playwright test tests/e2e/flavour-names.spec.ts --workers=2` — Setup offers the five themes and By seed; a game started with a theme shows that theme's names on selection and in the cards and history; Save and Load keep them.
  3. `npm test && npm run build` — Pass; CI's full browser suite is green.
- **Hazards**: Never consume or reorder the game RNG. Never alter topology, ownership or bonuses. Check spellings against the source for each island; no invented places.
