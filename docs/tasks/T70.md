# T70 Visible army totals and game playback controls

- **Kind**: feature
- **Issue**: #158 · **Branch**: `task/T70-army-totals-and-playback` · **Merge after**: T32, T33.
- **Implementer**: native Sol Medium under the owner's standing model authorization; timer cancellation and replay preservation need care.
- **Reviewer**: independent Claude Sonnet High via the T69 CLI backend.
- **Evidence**: owner playtest and explicit request, 2026-10-17. Seed 1994 can leave computer countries on one army. Parent inspection found no unexplained army changes across 309 handoffs; this does not resolve the owner's exact position. Existing `armyTotal` and the header score already calculate totals, but do not make them prominent enough. Existing battle speed/Stop controls do not pause computer play.
- **Owns**: `src/ui/**`, presentation-only parts of `src/styles.css`, `tests/ui/**`, `tests/e2e/playback-controls.spec.ts`, `docs/prototypes/new-game/T70/**`; append `RUN-NOTES.md`.
- **Scope**: Give each player a conspicuous, explicitly labelled total army count, updated after every ordinary action, including eliminated players. Keep game speed and Pause/Resume visible and keyboard usable throughout automatic turns and human combat. Add a very slow setting with at least two seconds between automatic actions. Pause stops all automatic computer and continuous human battle actions; resume continues the same match. Presentation controls add no game actions and consume no RNG. Gate manual match-changing input while paused; saving and replacing the match remain usable. Replacement/new game must cancel old callbacks. Keep existing routes, save formats and core rules unchanged. Pause is session presentation state, not serialized match history.
- **Done when**:
  1. `npx playwright test tests/e2e/playback-controls.spec.ts` — at both desktop sizes, all displayed totals equal the sum of owned map armies, change with play, and remain readable; Pause freezes history and armies, Resume continues, very slow delays actions, stale callbacks cannot play through pause or replacement. Continuous human fighting also pauses; paused manual actions are gated. Screenshots show the controls and totals.
  2. `npm test && npm run build` — existing rules, replay and presentation checks pass.
  3. `npx playwright test tests/e2e/computer-turn-flow.spec.ts tests/e2e/battle-controls.spec.ts` — existing turn and battle flows remain usable.
- **Hazards**: Do not confuse battle-specific Stop with global Pause; cancel both schedulers and invalidate queued callbacks. Do not change speed defaults or core policy to explain the unconfirmed report. Main preflights acceptance on baseline and disposable mock before implementation. Appearance remains the owner's judgment.
