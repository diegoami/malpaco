- **Scope**: Give each player a conspicuous, explicitly labelled total army count updated after every action, including eliminated players. Keep speed and Pause/Resume visible and keyboard usable throughout computer turns and human combat. Add a very slow setting with at least two seconds between automatic actions. Pause stops both automatic schedulers and gates manual match-changing input; resume continues the same match. Saving and replacement remain usable; replacement/new game cancels old callbacks. Add a popup full game event log, available while paused: initial deal, every ordinary action, turn/phase changes, reinforcements, combat casualties, captures, transfers, elimination and victory. Army changes identify player, region, reason and exact before/after counts; transfers are distinguished from losses. Reconstruct the complete log on load, append without duplicates and reset for a new match. Presentation controls/log add no game actions or RNG draws. Keep existing routes, save formats and core rules unchanged; pause is session state.
