- **Evidence**: isle-wars-archaeology `spec/reinforcement.md` (cited as claims only, rule 19):
  - C-REI-01: a seat's base reinforcement is `max(floor(provinceCount / 3), 2)`;
    `provinceCount` is the number of provinces the seat owns.
  - C-REI-02: a seat's island income is `islandIncome(state, seatId).total` (T09).
  - C-REI-03: the seat's total this turn is `base + islandIncome.total`.
  - Divisor 3 and minimum 2: standard Risk-style values `[designed]` — what was searched:
    T09's task file cites `isle-wars-archaeology` `spec/island-bonuses.md` for the same
    corpus family; this task assumes the corpus covers reinforcement, no independent
    search run in this session. Replace with `[confirmed]` once a finding cites them
    (rule 17).
- **Owns**: `src/core/reinforcement.ts` (new), `tests/core/reinforcement.test.ts` (new),
  one export line in `src/core/index.ts`.
- **Scope**: a pure function — suggested shape
  `reinforcementIncome(state, seatId) → { base, islandBonus, total, provinceCount }`,
  the seat's base, its island bonus (T09's export), their sum, and the province count
  that produced the base. No wall clock, no random, no DOM (rule 18). Out of scope:
  the turn-sequence that calls this (turn-sequence task owns when it runs); card-trade
  reinforcement (T22); pool placement.
- **Done when**:

     holding 0 / 1 / 2 provinces → `base == 2` (the minimum clamps the formula);
     `provinceCount == 3` → `base == 2`; `provinceCount == 6` → `base == 2`;
     `provinceCount == 7` → `base == 3`; held islands add their `bonus` to
     `islandBonus`; `total == base + islandBonus`; an eliminated seat returns the
     function's documented behaviour (chosen and recorded in the PR's Scope).

  (delegate to T09's export); importing DOM or I/O into `src/core` (the purity test
