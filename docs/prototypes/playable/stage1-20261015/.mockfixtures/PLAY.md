# Play Malpaco

Run `node serve.mjs` from this folder, then open <http://127.0.0.1:4175> in a desktop browser.

Choose seats and options in setup. Human seats take turns selecting a territory, choosing an adjacent enemy territory, resolving combat, and ending the turn. Computer seats take their turns automatically. Open **Help** from the game screen for the full controls. **Save** downloads a match file; **Load** opens one you saved. **New game** returns to setup.

The supported desktop layouts are 1280×800 and 1920×1080. Mobile layouts, online play, and cross-device save synchronization are not supported.
