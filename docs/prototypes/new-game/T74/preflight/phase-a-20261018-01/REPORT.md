## Disposable typed provider

The three proposed runtime modules are [pure derivation](proposal/generatedGeographyPresentation.ts), [worker](proposal/generatedGeographyPresentation.worker.ts), and [service](proposal/generatedGeographyPresentationService.ts). The pure module ports the approved canonical network/flow without arithmetic or constants changes. It returns original logical ids, native polygons/anchors/routes, exact drawing version and contentKey. Every nested output is frozen; output border/membership arrays are owned copies, so caller data is neither changed nor frozen. There are no runtime Node/prototype-filesystem imports.

The service snapshots input, deduplicates concurrent content requests, caches eight immutable completed drawings using bounded LRU [designed], and keys by canonical JSON of complete accepted geometry plus version/constants. Exact keys avoid digest collisions; they are larger than hashes. Same-seed different geometry and distinct versions do not alias. Subscriber cancellation, fully cancelled stale work, disposal, bad identities, explicit derivation failures/retry and transport errors are covered. A terminal worker error rejects current AND future requests immediately: caller must dispose/recreate the service before retry. Cancellation does not preempt a synchronous worker calculation already executing; disposal terminates the worker. [API/integration contract](proposal/API.md) provides protocol details and limitations.

A real-browser dedicated-worker smoke shows responsive main-thread timers before completion, concurrent-result/cache identity, deep immutability, exact caller bytes, explicit disposed rejection and a frozen1994drawing match, with zero page errors. [Smoke result](proposal/browser-worker-smoke.json) retains the actual returned geometry and288timer ticks observed before completion.
