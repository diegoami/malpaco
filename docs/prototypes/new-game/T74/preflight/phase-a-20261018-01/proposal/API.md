This is a disposable proposal for parent acceptance, with no playable activation.

`derivePresentation(acceptedGeometry)` returns native SVG coordinates, original logical country/island/route ids, `drawingVersion`, and `contentKey`. The polygons provide both paint and hit geometry; the full40native-unit reservation is independently checked. Input/save geometries remain in their original fixed-point units. Returned nested arrays are frozen and own their border/membership arrays, so freezing output does not freeze caller data.

The drawing version is exactly `t72-relocated-flow-spread-v2`. The four configurable constants remain .65strength,160steps,2spacing and2048grid; all remaining field/canonical-network constants are the exact approved ones and belong to that version. There is no gameplay RNG argument or draw. No Node module or prototype filesystem import enters the three proposal runtime modules.

`new PresentationService(workerPort, capacity=8, version=DRAWING_VERSION)` offers `request(geometry, AbortSignal?)` and `dispose()`. `createPresentationService()` creates the dedicated browser worker. Eight completed entries is a proposed bounded LRU policy [designed], not an observed requirement. Identical pending requests share work. The identity is canonical JSON of complete accepted geometry, drawing version and constants; its exact string avoids hash collisions, at the cost of larger keys than a digest. Same-seed different geometry and different versions cannot alias. Every request snapshots input before transport; returned results are separately cloned and deeply frozen.

Protocol: derive `{kind:'derive',id,key,version,geometry}` or cancel `{kind:'cancel',id}`; success `{kind:'success',id,key,version,value}` or failure `{kind:'failure',id,key,version,message}`. Cancelled/obsolete ids cannot populate cache or settle later subscribers. Pending requests reject on errors/disposal; disposal removes listeners and terminates the worker.

A derivation failure rejects its subscribers and is retryable on the same service. A worker `error` is terminal: current and future requests fail explicitly, and the host must dispose/recreate the service before retry. No automatic recovery policy is implied. Cancellation rejects an individual subscriber; when none remain it marks the request stale. A synchronous derivation already executing inside the worker cannot read its cancel message until it returns, so cancellation is not a guarantee of immediate CPU preemption. Disposal does terminate computation.

Preserve accessible logical names, actual production names in map-array order, four44×20badges,14pxcounts,12pxbold conditional names, centre stars and existing selection/keyboard behavior. The sidecar intentionally leaves live conditional-name placement to T75/#174.

Evidence is limited to the frozen13seed corpus:12accepted maps and398's50-attempt refusal. This is not a success-rate claim over arbitrary seeds or a cross-platform font/performance guarantee. The pure proposal is not a general hostile-input geometry validator, and broader output-safety assurance outside the frozen corpus remains a parent acceptance question. The worker isolates expensive computation; it does not make that computation cheap.
