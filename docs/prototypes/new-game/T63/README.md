# Adopted coast-first reference

This is the original malpaco reference for T26. `board.json` is byte-identical
to owner-selected T60 A: 46 countries, 9 islands, 61 land borders, 15 sea links,
with the same opening armies, ownership, production and bonuses. The approved
[T62 contract](../T62/README.md) applies; old midpoint conflicts remain in the
immutable T60/T62 reports. T61 corrected the false cell residuals. The owner’s
[contract approval](https://github.com/diegoami/malpaco/pull/121#issuecomment-6216037987)
and source hashes are recorded in `provenance.json`.

Open `preview.html` directly; it has no network/runtime dependencies. Select by
click, Enter or Space; arrows move focus. Neighbours and incident sea routes
highlight. Topology opens/closes the income summary; Export SVG downloads the
actual current drawing. `map.svg` is the initial standalone drawing. A's SVG,
including fonts, colours and coast/route geometry, is reused unchanged apart
from invisible accessibility state attributes. The 80px header adds controls;
no map polish, gameplay or production integration is included.

Reproduce with `node docs/prototypes/new-game/T63/build.mjs`. It always writes a
fresh `evidence/build-*` directory; it never overwrites the deliverables or any
measured output. The three files are generated by `construct.mjs` from the pinned
A source and `render.mjs`. `node docs/prototypes/new-game/T63/verify.mjs` checks
all adopted groups, exact full identity, 61/15 edges, every generated byte and
source fingerprints. `node --test docs/prototypes/new-game/T63/acceptance.test.mjs`
checks opening, graph, bonus, geometry and reservation negatives independently
of the identity refusal. Parent guards remain unchanged from commit db88a3d.

Run `node docs/prototypes/new-game/T63/browser.mjs` in the repository’s pinned
Playwright container. At all three specified sizes it checks every country by
click and keyboard, visible neighbour/route styling, all 40px hit-square corners,
actual label/count bounds and visibility, all arrow directions, current-map SVG
export, topology controls, route geometry and coast ports. Page/console errors
reject. It requires all three viewports to complete. Screenshots support owner
inspection; these checks do not establish beauty or player comprehension.
