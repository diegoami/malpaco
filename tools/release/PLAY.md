# Play Malpaco

Run `node serve.mjs` from this folder, then open <http://127.0.0.1:4175> in a desktop browser.

Choose 2–4 seats and either all-human play or one human seat against computer-controlled opponents. Setup provides an initial reinforcement pool to place on your territories. During a turn, spend reinforcements on owned territories, then choose **Start combat** before attacking. Select one of your territories, choose an adjacent enemy territory, resolve combat, and end the turn. Computer turns run automatically. Open **Help** from the game screen for the full controls. **Save** downloads a match file; **Load** opens one you saved. **New game** returns to setup.

The supported desktop layouts are 1280×800 and 1920×1080. Mobile layouts, online play, and cross-device save synchronization are not supported.
